# 吉林大学体育馆前端仿制设计

## 目标

在空工作区中创建一个 Vue 3 + Vite 单页应用，仿制吉林大学“智慧场馆客户服务管理平台”中作业要求涉及的移动端页面。成品只实现前端展示和页面级导航，不连接原站后端，不提交预约或个人信息。

页面应在手机视口下尽量贴近参考截图，并在桌面浏览器中以移动端画布居中显示。个人中心固定显示姓名“李子涵”、学号“87240433”。

## 页面与路由

应用使用 Vue Router，并设置四类路由：

1. `/venues`：场馆选择页，对应参考图 4。
2. `/home/:venueId`：场馆首页，对应参考图 1 和图 5。
3. `/reserve/:venueId`：预约项目列表，对应参考图 2 和图 6。
4. `/profile`：个人中心，对应参考图 3 和图 7。

默认进入 `/venues`。场馆 ID 使用 `song` 和 `qianwei`，选择后进入对应首页。底部导航保留“首页 / 预约 / 我的”，高亮状态与当前路由同步。

## 组件结构

- `MobileShell`：移动端画布、背景和页面安全区。
- `BottomNav`：固定底部导航和激活状态。
- `VenuePickerView`：平台 Logo、标题和两张场馆入口卡片。
- `VenueHomeView`：场馆标题、切换入口、轮播主图、地址与联系电话、场馆安排和在线功能。
- `ReservationView`：顶部“场地”标签和项目卡片列表。
- `ProfileView`：渐变个人资料头部、“我的助手”卡片和底部导航。
- `VenueCard`、`FeatureItem`、`SportCard`：复用的展示组件。
- `src/data/venues.js`：静态场馆、项目和图片映射，替代后端接口。

每个组件只负责一个可识别区域，页面组件通过静态数据组合它们，避免把全部布局放进一个文件。

## 视觉实现

页面基于原站样式值和截图比例重建：

- 设计基准宽度为 390px，桌面端最大宽度为 430px。
- 主背景为浅灰色，内容卡片为白色，圆角与间距按原站移动端比例实现。
- 主色使用原站的浅蓝色 `#7ecef4`，个人中心顶部使用蓝绿渐变。
- 底部导航固定在画布底部，保留图标、文字和选中态。
- 场馆首页主图使用原站图片并按截图比例裁切。
- 预约项目图片、按钮尺寸和文字层级按参考图复现。
- 允许不同浏览器字体渲染带来少量差异，但布局、颜色、图片和层次应明显一致。

## 交互范围

- 场馆入口可点击，并更新当前场馆。
- “查看其他校区”返回场馆选择页。
- 底部三个导航项可切换页面。
- “场地预约”进入当前场馆的预约项目列表。
- “预约场地”和未实现的功能按钮显示轻量提示，不进入后端流程。
- 轮播图可自动切换，也可通过圆点切换。

## 错误处理

所有数据和资源均为本地静态内容。图片加载失败时显示带场馆或项目名称的渐变占位块；未知场馆 ID 自动回到宋治平体育馆。不存在的路由重定向到场馆选择页。
