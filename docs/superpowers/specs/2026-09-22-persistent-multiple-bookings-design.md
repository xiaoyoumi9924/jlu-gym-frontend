# 浏览器本地多预约设计

## 目标

让用户在同一浏览器和同一域名下关闭并重新打开页面后，仍能看到此前创建的全部演示预约。

## 已确认需求

1. 每次新建预约都新增一条，不覆盖旧记录。
2. “我的预约”显示全部预约。
3. 每条预约可以单独查看详情或取消。
4. 取消只把该条记录改为“已取消”，不删除记录。
5. 页面不提供清除或删除预约的功能。
6. 数据仅保存在访问者浏览器的 `localStorage`，不上传服务器。

## 数据与兼容方案

- 新存储键为 `jlu-gym-mock-bookings`，值为预约对象数组。
- 每条预约继续使用现有 `orderNo` 作为唯一标识。
- `saveMockBooking(input)` 读取现有数组并把新预约追加到末尾。
- `getMockBookings()` 返回全部记录；`getMockBooking(orderNo)` 返回指定记录。
- `cancelMockBooking(orderNo)` 只更新目标记录的 `status`，保留其他字段和其他预约。
- 如果新键尚不存在，但旧版 `sessionStorage` 中存在 `jlu-gym-mock-booking`，首次读取时把旧记录迁移成数组并写入新键。
- 损坏或类型错误的浏览器数据按空列表处理，页面不能崩溃。

## 页面与路由

- “我的预约”通过 `v-for` 显示全部记录，以 `orderNo` 作为 key。
- “查看详情”进入 `#/my-bookings/detail/:orderNo`。
- 详情页根据路由中的 `orderNo` 读取对应预约。
- “取消预约”把当前卡片对应记录改为“已取消”，卡片仍然保留。
- 空数组时继续显示现有“暂无预约”状态。

## 非目标

- 不增加服务器、数据库、账号同步或网络请求。
- 不增加清除、删除、批量操作或自动过期功能。
- 不改变预约设置表单和入场码视觉样式。
